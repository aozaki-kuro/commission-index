## Design Context

### Users

The primary user is the site's owner and content maintainer. Commission Admin is a private,
focused tool for creating, finding, editing, ordering, and publishing commission records. Work
usually follows a short sequence: select an item, make a precise change, save, and continue.

### Brand Personality

Restrained, precise, and private. Copy is concise English with a practical, editorial-tool tone.
The interface should feel calm and trustworthy while preserving a subtle archival character.

### Aesthetic Direction

Preserve the existing neutral light/dark UI, IBM Plex Sans body text, Berkeley Mono metadata,
soft borders, restrained shadows, and rounded surfaces. Brand pink may appear only as a subtle
accent; semantic colors remain reserved for selection, success, warning, and danger. Desktop uses
compact centered workspaces, while narrow touch screens adapt dialogs to full-screen tools.

### Design Principles

1. Optimize the maintenance flow: keep select, adjust, confirm, and continue in one context.
2. Make exact output contracts visible before save, including dimensions, format, and quality.
3. Put constraints in the interaction model so invalid image positions cannot be created.
4. Preserve full functionality across pointer, touch, keyboard, narrow screens, and 200% text zoom.
5. Prefer existing Radix primitives and established visual contracts over parallel UI patterns.
6. Keep motion short, functional, and compatible with reduced-motion preferences.
