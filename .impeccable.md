## Design Context

### Users

The primary user is the site's owner and content maintainer. Commission Admin is a private,
focused tool for creating, finding, editing, ordering, and publishing commission records. Work
usually follows a short sequence: select an item, make a precise change, save, and continue.

### Brand Personality

Restrained, precise, and private. Copy is concise English with a practical, editorial-tool tone.
The interface should feel calm and trustworthy while preserving a subtle archival character.

### Aesthetic Direction

Use a calm collection workspace with Vercel-inspired black/white grayscale, IBM Plex Sans body
text, Berkeley Mono metadata, fine borders, and restrained rounding. Brand pink appears only as
a small accent; semantic colors remain reserved for selection, success, warning, and danger.
Use high-opacity frosted glass selectively on navigation, sticky save bars, and floating notices;
keep editing and artwork surfaces opaque. Desktop has a persistent navigation rail and a shared
1600px page shell: titles, dividers, and primary surfaces keep the same edges across routes.
Adjust image and field columns within that shell, not entire page widths. Grid density follows
container width rather than display pixel ratio. Mobile exposes every destination and adapts dialogs
to full-screen tools. Avoid nested cards, repeated headings, and oversized dashboard metrics.

### Design Principles

1. Optimize the maintenance flow: keep select, adjust, confirm, and continue in one context.
2. Make exact output contracts visible before save, including dimensions, format, and quality.
3. Put constraints in the interaction model so invalid image positions cannot be created.
4. Preserve full functionality across pointer, touch, keyboard, narrow screens, and 200% text zoom.
5. Prefer existing Radix primitives and established visual contracts over parallel UI patterns.
6. Keep motion short, functional, and compatible with reduced-motion preferences.
7. Show character states as persistent Active / Archived text, including during rename and ordering;
   Archived means folded by default on the public site, not hidden or outdated data.
